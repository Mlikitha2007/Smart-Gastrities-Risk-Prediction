# Smart Gastritis Risk Prediction

## Project Overview
Smart Gastritis Risk Prediction is a machine learning-based case study that predicts gastritis risk categories using patient-related health information. It uses a Random Forest Classifier to identify patterns in the dataset and perform risk classification.

## Objectives
- Analyze patient-related health information.
- Identify patterns associated with gastritis risk.
- Develop a machine learning classification model.
- Evaluate model performance using classification metrics.

## Dataset
The project uses a synthetic gastritis risk prediction dataset containing patient-related health attributes.

**Target Variable:** `Gastritis_Risk_Label`

## Algorithm Used
**Random Forest Classifier**

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Spyder IDE

## Methodology
1. Dataset loading and exploration.
2. Data preprocessing.
3. Handling missing values and duplicate records.
4. Encoding categorical features.
5. Training and testing the model.
6. Model evaluation.

## Disclaimer
This project is developed for educational purposes using a synthetic dataset. It is not intended for medical diagnosis or to replace professional medical advice.
